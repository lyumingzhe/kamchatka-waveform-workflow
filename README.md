# Kamchatka Earthquake Waveform Modelling Workflow

Custom scripts and automated workflow for focal mechanism inversion, surface-wave double-difference relocation, and path-calibrated back projection in the Kamchatka subduction zone.

### Note on Availability
This repository contains scripts used in the study submitted to Nature Communications. The complete codebase, documentation, and sample datasets are currently being organized and will be fully deposited and archived with a permanent DOI upon final acceptance of the manuscript.

For inquiries or access during the peer-review process, please contact the corresponding author.
